\# Banking API



\## Features

\- User registration \& login

\- Deposit money

\- Transfer money (atomic transactions)

\- Transaction history

\- JWT authentication



\## Tech Stack

\- FastAPI

\- SQLAlchemy

\- SQLite

\- JWT (python-jose)



\## Run Locally



pip install -r requirements.txt

python init\_db.py

python -m uvicorn main:app --reload

http://127.0.0.1:8000/docs
